# Rich1eYT Website

Free static website for Adebisi Farouk (Rich1eYT).

## Publish with GitHub Pages

1. Create a repository named exactly: `rich1eyt.github.io`
2. Upload `index.html` to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, choose GitHub Actions or deploy from the `main` branch if offered.
5. Your site should become available at:
   https://rich1eyt.github.io/

The site already includes basic SEO metadata and Person/ProfilePage structured data.
